# Projeção orçamentária FAPDF

Dashboard em React + Vite do convênio FAPDF / Finatec (projeto 8072, TOA nº 382/2025). Os cálculos rodam no navegador. O cenário padrão de **+12 meses** mostra o disponível para computadores e a quantidade que cabe no saldo.

O cronograma físico-financeiro continua na raiz deste repositório. Este app fica isolado em `fapdf-dashboard/`.

```bash
cd fapdf-dashboard
npm install
npm run dev
```

Build de produção: `npm run build` (saída em `dist/`).
